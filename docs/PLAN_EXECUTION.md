## 产品化验收的三条通用标准

PLAN 的 DoD 大多是工程指标（测试、延迟、拦截率）。一个阶段要算"产品可用"，还得多过这三条：

1. **孩子有入口**：能从导航走到，不依赖实验台页面、手写 JSON 或 curl。
2. **失败有降级**：模型/引擎/网络任意一环挂掉，孩子看到的是一句能理解的话，不是一个错误码。
3. **数据留痕可核对**：做过的题、看过的课、说过的对话（家长开启时）能查回来，且不泄露判卷依据。
