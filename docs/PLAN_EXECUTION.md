## 产品化验收的三条通用标准

PLAN 的 DoD 大多是工程指标（测试、延迟、拦截率）。一个阶段要算"产品可用"，还得多过这三条：

1. **孩子有入口**：能从导航走到，不依赖实验台页面、手写 JSON 或 curl。
2. **失败有降级**：模型/引擎/网络任意一环挂掉，孩子看到的是一句能理解的话，不是一个错误码。
3. **数据留痕可核对**：做过的题、看过的课、说过的对话（家长开启时）能查回来，且不泄露判卷依据。

## 本次推进（2026-11-07 第四轮：P1 从"拦"转向"养"）

> 上一轮把"不喂答案"守住了，但孩子在全系统里仍然只产出一个答案字符串。
> 这一轮补的是"养"：让他说出自己的想法，并让家长看得见他在不在自己学。

- **元认知两问**：答错后先问「你觉得错在哪」（选一个），再进归因；第一次见这道题
  就零提示做对时，请他讲讲怎么想的。两句话都记成 `reflection` 事件，
  标 `ai_unverified`——判不了对错、不进掌握度、不点亮星，只作为"会不会讲"的记录。
  自由输入过一遍安检。
- **独立性看板**：`GET /api/v1/parent/independence` 给出新题首答靠自己比例、
  提示深度分布、看过几次解析、问一道题几次、重复交了几次；`GET /parent/reflections`
  回孩子自己说过的原话。家长页新增「他是在自己学吗」面板。
  统计口径全部来自已有记录，不额外让模型判任何东西。
- `POST /api/v1/practice/reflection` 落库；`/practice/submit` 新增 `askWhy` 标记
  （第一次见 + 零提示 + 做对才为真）。

回归：`apps/server/tests/p1-metacognition.test.ts`（13 条）。

## 本次推进（2026-11-07 第三轮：P0 教学承诺修正）

> 依据 `docs/REVIEW_2026-11-07_GOALS.md`。这一轮不加新功能，只把"辅助不依赖 / 点亮=理解"
> 从界面流程挪到服务端，并修掉两处证据断线。

- **讲解入口闸（宪法第 2 条）**：`POST /api/v1/explain` 对孩子只在**这道题自己走过一遍**
  （答对过，或服务端记到三级提示用完）时才给解析；`fallback.analysis` 不再对任意 questionId 敞开。
  孩子真拿到解析时记 `analysis_view` 事件。
- **「问一道题」纳入家长开关与时长闸**：`MODULES` 新增 `ask`（家长中心自动出现开关），
  `/api/v1/ask` 与 `/ask/photo/question` 先过模块闸再过每日时长闸。
- **乱打字不再等于跳题**：判不准且明显没在作答（「不会」「？？？」）**不写 attempt**，
  只留 `giveup` 事件，题留在原地；前端给出「我卡住了」的诚实出口（不必先交错答案）。
  判准不准也由服务端按队列项判定，不信客户端自报的 `source`/`hintLevelUsed`。
- **点亮要独立证据（宪法第 1 条）**：`masteryBand` 现在还要 `evidence.ts` 推导出的
  独立证据：≥3 条、覆盖 ≥2 道不同题、跨 ≥1 天、至少一条发生在孩子第一次见那道题时；
  零提示、作答前没看过这道题的解析、且只算题目主节点。
  同题同日最多认「一次错 + 一次对」——重复交错答案不再连续 ×0.6 把星打回暗。
- **证据断线**：探针来源按队列项判定（前端不传 `source` 也回填）；归因先扣掉本次错答
  再加权候选，根因不再塌缩成题目自己那个节点。
- **家长试做留痕不计分**：`attempts.actor` 区分 child/parent；家长试做不进掌握度，
  前端也不再拿家长的停留时间扣孩子的时长。
- 顺手修：错因条形图 `share` 被重复 ×100（每条都满宽）。

回归：`apps/server/tests/p0-gates.test.ts`（14 条，全部经 HTTP）。
