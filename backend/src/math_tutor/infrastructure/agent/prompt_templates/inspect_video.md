## 评审项目

### A. 视觉布局（基础，人看起来正常）
逐帧检查并区分两级：
- **布局硬伤**（任一命中即 bad）：文字或图形互相重叠到**无法辨认**；关键内容被画面边缘
  裁切；题目卡缺失或不可读；乱码/损坏的符号。必须写明帧时间戳 + anchor + 涉及对象。
- **布局瑕疵**（写进"问题"，不单独判 bad）：轻微贴边、间距偏小、字号偏小但可读、
  颜色对比偏弱、个别帧稍显拥挤。

### B. 教学价值（核心）
对每项打 0/1/2 分。打分依据是**画面可见证据**，与计划路径是否逐字一致无关：
- B1 **视觉论证连贯性**：这些帧连起来是否构成一条能看懂的视觉论证（任何数学上等价的
  路径都算）？ 0=画面之间无逻辑关联 / 1=有主线但断裂 / 2=连贯成立
- B2 **动画语义**：画面变化是否承载数学含义（变换、增减、对比、守恒）？
  0=只有翻页式文字替换 / 1=部分有语义 / 2=主要变化都对应推理步骤
- B3 **文字依赖度**：把所有 Text 关掉后，画面还能让人看懂"在讲什么"吗？
  0=完全看不出 / 1=部分能看出 / 2=可以
- B4 **关系/变化可见**：核心数学关系、变化或不变量是否用图形显式揭示？
  0=没揭示 / 1=隐含 / 2=显式揭示
- B5 **数学契约一致性**：可见数值、标签、状态变化和结论是否与已验证答案/步骤一致？
  0=存在矛盾或讲错 / 1=截图证据不足但未见矛盾 / 2=关键关系和结论均可核对
- B6 **本质可见性**：学生能否从图形变化中看出"为什么答案成立"（而不是只看到计算和
  结论）？essence_rationale 是参考路径，等价路径同样算兑现。
  0=画面完全没有揭示原因，只有计算/结论 / 1=部分揭示 / 2=原因清楚可见

### C. 失败模式黑名单（命中须给出帧证据，命中任一即 bad）
- **PPT 翻页**：存在连续 ≥3 个采样帧，帧间只有文字换行/替换，没有任何图形对象变化。
  必须列出这些帧的时间戳。
- **公式墙**：某一帧内同时出现 ≥3 行公式且没有图形锚点。必须写明帧时间戳。
- **文字搬运**：所有采样帧中，除题目卡外没有任何数学图形（坐标系、图形对象、数量图）。
- **符号悬空**：关键符号从头到尾没有对应的稳定图形对象，观众只能阅读符号链。
注意：视频整体"动画多不多"由确定性检测的 active_transition_fraction 判断，你看到的是
离散采样帧，**不要**据此断言"动画时长占比不足"。

## 判分规则（汇总）
- 确定性 critical_issues 任一 → **bad**
- 布局硬伤任一 → **bad**
- 命中黑名单任一（附帧证据） → **bad**
- B6 = 0（画面完全没有揭示原因） → **bad**
- B 段总分 < 6 → **bad**
- B 段总分 6–8 且无上述硬失败 → **acceptable**（可交付，问题写入报告）
- B 段总分 ≥ 9 但 B5 < 2（数学未能完全核对）→ **acceptable**
- B 段总分 ≥ 9 且 B5 = 2 且无上述硬失败 → **good**
