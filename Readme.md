# 🎓 MathTutor · 家庭本地的 AI 原生学习环境（数学 + 英语）

> 一张会点亮的知识地图，一位不喂答案的导师，一套能让孩子自己说出"我是怎么想的"的学习闭环。
>
> 不是为了考 100 分，而是知道如何考 100 分。

家庭本地部署：孩子每天做少量精选题；做错了先走提示阶梯自己再试，仍不会才看讲解，
再用一道**没见过的同类题**证明自己会了。英语有词汇、阅读、语法、听力、写作和口语对练。
模型、语音识别、语音合成全部跑在本机（LM Studio / oMLX 等 OpenAI 兼容端点 + faster-whisper + 系统语音），
平板在同一局域网访问。

**先读「⚠️ 现状与局限」再决定要不要用。** 这是一个人维护的项目，很多能力有代码、有测试，
但还**没有被真实孩子长期使用验证过**。

---

## ⚠️ 现状与局限（请先读这一节）

### 1. 还没有效果证据

- 真实使用数据：**1 个孩子、5 天、17 次作答**（2026-08-10 ~ 08-14），之后没有持续使用。
- 前测 / 后测 / 保持率的测评骨架已经有了（`/api/v1/assessment`），但**还没有任何一组完整数据**。
  所以"这套方式比单纯刷题更有效"目前**没有证据**——这是 `docs/PLAN.md` 里写明的完成标准，还没达到。
- 全部测试（TS 725、Python 447、Playwright 40、红队 64）证明的是"不崩、规则被执行"，
  **不是**"孩子学得更好"。e2e 也不接真实模型。

### 2. Manim 视频讲解：质量不稳定，而且很慢

这是项目最初的方向（题目 → Manim 教学视频），也是最不成功的部分：

- **质量门禁通过率低**：30 道黄金题实测（`data/bench/golden-engine-20261105-0942-regraded.json`，
  本地 qwen 模型），答案正确 28/30，但视频**达到质量门禁的只有 13/30**；
  14 道是"已交付当前最佳候选（未达到质量门禁）"，3 道没编译出来。
- **Manim 被当成幻灯片用**：对历史会话统计，模型写出的代码以 `Text`、`VGroup`、`FadeIn` 为主，
  `MathTex` 只出现 1 次、`ValueTracker` 1 次，公式变形和 3D 为 0（`docs/PLAN.md` 4.1）。
  也就是说，Manim 真正擅长的东西几乎没用上。
- **本地生成非常慢**：一条视频中位 **340 秒**、P90 **1142 秒（约 19 分钟）**（同一份黄金集）；
  吞吐基准中位 170 秒（`data/bench/throughput-001.json`）。各阶段里最慢的是
  模型写 Manim 代码（平均约 105 秒）和视觉模型审片（平均约 164 秒）。
  孩子不可能坐在屏幕前等这么久。
- **所以现在的默认讲解是 Web 动画**（SceneSpec → SVG 逐拍播放，秒级出现、无 ffmpeg），
  Manim 只作为家长手动触发的"高级视频"。即便如此，Web 讲解在孩子的真实路径上也很少被生成过
  ——模型离线、生成中、失败三种情况下，孩子看到的都是文字版解析。
- PLAN 阶段 6（Manim 特性模板：公式变形 / 参数变化 / 3D / 线性变换，模板覆盖的题不再让模型写码）**没有开始**。

`services/video-engine/media/` 下早期生成的数千个视频、截图与评审产物**不再随仓库提交**
（它们是运行产物，不是源码），留在本机即可。

### 3. 其他依赖本地模型的路径也慢

本地模型（实测 qwen 27B 级别）下的经验值，供估计等待时间：

| 路径 | 典型耗时 | 模型不可用时 |
|---|---|---|
| 提示阶梯（一级提示） | 1 ~ 3 秒 | 退回三条通用静态提示 |
| 课堂 generate 模式 | 十几秒到 45 秒（超时上限） | 自动退回离线组课（compose） |
| 「问一道题」（引擎解题 + 验证） | 数分钟 | 诚实失败，不收题 |
| 英语写作反馈（两次评分做一致性检查） | 数秒 ~ 十几秒 | 503，"写作反馈暂时给不了" |
| 口语对练一轮（ASR + 模型 + TTS） | 实测约 1 ~ 2 秒（ASR 热态 ~230ms、TTS ~1.1s） | ASR 不可用时 503；TTS 不可用时有文字无声音 |
| 听力材料首次合成 | 每篇十几秒（之后按篇缓存） | 诚实说做不了，**不**把原文给出去 |

练习组卷、规则判卷、SM-2、掌握度、规划器都是确定性代码，**不经过模型**，断网可用。

### 4. 内容薄、而且没人核验过

- **数学题库 288 道**，其中 282 道是小学高年级（多为奥数风格的长应用题），
  小学低年级只有 4 道、初中只有 2 道。**58 道"如图"题的原图缺失**，已自动排除出组卷。
  每个知识点平均只有 2 ~ 3 道题——前测里常常凑不齐全新题（系统会如实标 `reused`），
  "同题型换题"也经常只能退到"同节点的另一道题"。
- **知识图谱 123 个数学节点全部是模型生成的（`verified = 0`）**。星图、课堂、讲解里
  "这是什么 / 为什么学"那几句话都没人核对过。家长可以在星图里逐个核验。
- **英语**：词汇 96 个、分级阅读 4 篇（听力复用同样 4 篇）、语法 115 个单元（来自教材目录）
  但只有 18 道语法练习题、口语情景 6 个、写作任务 5 个。够试用，不够一学期。
- 英语语法主线由一本受版权保护的教材的**单元目录**确定性生成；教材 PDF 本身**不随仓库分发**，
  仓库里只有生成好的结构 `subjects/english/grammar.graph.json`。

### 5. 设计上刻意不做的事

- **不打分**：英语写作和口语都是 `ai_unverified`，只给反馈与建议，**不进掌握度、不点亮星**。
- **不做发音评测**。
- **测评不改变掌握度**：前测 / 后测 / 保持率单独记账，没有提示，作答中不给对错。
- **孩子自注册**（最多 5 个）：方便，但意味着孩子可以新建账号绕开某个账号上的时长与模块设置；
  家长能在孩子列表里看到所有账号。

### 5b. 已知还开着的口子（2026-11-08 对抗审查后仍未修）

- **听力和阅读共用同 4 篇短文**：听力不下发原文，但孩子可以切到「阅读」看到全文再回来答听力。
  听力本来就不进掌握度，所以只影响孩子自己的练习效果；要堵得给听力单独配材料。
- **语法单元页的教材原句**：会**直接填上空**的例句已经从和题目同屏的讲解里去掉了，
  但"同一个结构、换了主语"的例句（`My favourite colour is blue.` 对 `My name ___ Lisa.`）照样在——
  那是讲解本身，删了就没法讲。孩子照着结构类推答对，算不算会，这里没有判据。
- **视频讲解文件**走引擎的 `/api/v1/media` 透传，没有按题把门；视频 URL 只出现在已经过了讲解闸的响应里。
- **引擎没有鉴权**：默认只听 `127.0.0.1`（docker-compose 里只映射到宿主机回环）。
  改成 `0.0.0.0` 让局域网可达之前，先想清楚谁能连到它。

### 6. 没做的 PLAN 阶段

阶段 6（Manim 特性模板）、7（物理 / STEAM）、8（PBL、AI 素养、费曼 / 给 AI 挑错）、
9（引擎编排迁 TS）都**没有开始**。进度台账见 `docs/PLAN_EXECUTION.md`，
最近一次对抗审查见 `docs/REVIEW_2026-11-07_GOALS.md`。

## 教学法宪法（凌驾于一切功能之上）

1. **理解由行为验证，不由观看验证**——点亮一个知识点要有独立证据：≥3 次、覆盖 ≥2 道不同的题、
   跨 ≥1 天、至少一次是第一次见那道题时零提示做对；看过解析后再做对只算回忆
2. **不喂答案**——答错先走提示阶梯（服务端逐级发放）；讲解里的解析要孩子自己走过一遍这道题才给
3. **复习 = 同题型换题再练**——按题干骨架找"换个数字的同一道题"，绝不重看原题答案式复习
4. **归因必须带证据**——错因是图谱坐标，附置信度与依据链；探针作答是证据，图遍历只是假设
5. **数形结合、揭示本质**——图形承担论证，文字关掉仍能看懂（这一条目前做得最不够，见局限 2、4）
6. **未核验的知识不承重**——节点 verified 或有实证才做根因归因；AI 的判断永不进掌握度

## 孩子能用的东西

| 视图 | 做什么 |
|---|---|
| **练习**（默认） | 新孩子先做摸底组；之后今日组卷（到期复习 > 探针 > 弱点 > 新题 + 1 挑战）→ 作答 → 提示阶梯（「我卡住了」可直接要提示）→ 答错先说说自己错在哪 → 归因 → 讲解 → 变式题；阶段测评卡片也在这里 |
| **课堂** | 一节小课：讲 → 停下来提问（这一拍不能跳过）→ 答完回到原处 → 小结；离线组课永远可用，模型可用时可以 AI 讲解 |
| **英语** | 词汇（SM-2）· 阅读（答完给原文依据）· 语法（115 单元，学 + 练 + 提示）· 听力（只给声音不给原文）· 写作（量规反馈，不打分）· 开口说（6 个情景，本地语音） |
| **问一道题** | 题库外的题：先自己做，答错才一级级给提示（家长可以关掉、受时长限制） |
| **星图 / 错题本 / 探索** | 掌握度地图；错题根因与依据；苏格拉底式对话与动手组件（结论要自己先发现） |

家长额外有：讲解（Manim）、录题、题库（含题型提案）、教材、AI 实验台、家长中心
（错因模式、趋势、判卷抽检、「他是在自己学吗」独立性看板、阶段测评对比、对话与口语记录、模块开关、时长上限）。

```
mathtutor/
├─ packages/schema          # zod 单一类型真源
├─ packages/knowledge       # 图算法、lint 不变量、离线定位器
├─ packages/core            # 学科注册表、证据与验证等级
├─ packages/llm-client      # OpenAI 兼容客户端（LOCAL_ONLY 默认拒绝云端）
├─ packages/explainer-web   # Web 时间轴播放器：SceneSpec → SVG（seek / 补间 / 像素基线）
├─ packages/classroom-runtime # 课堂状态机（改写自 OpenMAIC，见 THIRD_PARTY_NOTICES.md）
├─ packages/safety          # 内容安全：纯规则三态裁决
├─ packages/widgets         # 十个动手组件 + 纯函数状态机
├─ subjects/math|english    # 学科包：判卷器、英语内容（词汇/阅读/口语/写作）、语法图
├─ apps/server              # Hono TS 单体：对外唯一入口
├─ apps/web                 # React 19 前端
├─ services/video-engine    # Python compute-worker：Manim 渲染、图形几何、本地 ASR / TTS
├─ data/knowledge/          # 知识层 file-first（图谱 / 题型 / 题目，git 版本化 + lint）
├─ data/red-team/           # 安全红队用例（合成样本）
└─ data/bench/ data/golden/ # 基准与黄金集
```

## 🚀 快速开始

```bash
# 0) 本地模型：LM Studio / oMLX 起一个 OpenAI 兼容服务，复制 .env.example 为 .env 并填好
#    LLM_API_BASE / LLM_MODEL；LOCAL_ONLY=1 默认开启（拒绝云端端点）

# 1) 安装与全量检查
pnpm install && pnpm -r build
cd services/video-engine && uv sync --extra dev --extra speech && cd ../..   # speech = 本地语音识别
pnpm verify          # 类型检查 → 构建 → 单测 → 对齐评测 → 安全红队 → pytest → Playwright

# 2) 三个进程
cd services/video-engine && .venv/bin/python -m math_tutor.api.main &   # compute-worker :8000
node apps/server/dist/index.js &                                        # 网关 :8080（对外唯一入口）
cd apps/web && npx vite                                                 # 前端 :5173
```

- 引擎没起时可以 `ALLOW_ENGINE_OFFLINE=1` 启动网关：讲解、问一道题、语音不可用，其余照常。
- 本地语音识别首次使用会从 Hugging Face 下载 `tiny.en`（约 75MB）；本地语音合成用 macOS 自带的
  `say`（其他系统可配 `TTS_API_BASE` 指向一个 OpenAI 兼容的 `/audio/speech`）。都需要 `ffmpeg`。
- 本机开了系统代理时，curl 调试本地端口要加 `--noproxy '*'`。

## 数据纪律

- **知识层 file-first**：图谱、题型、题目是 git 版本化 JSON，修改经 lint 闸门
- **学习者层 DB-first**：`data/app.sqlite`（不入 git）；掌握度是证据的投影，固定参数启发式，永不宣称精准诊断
- **答案永不下发**：练习、课堂、测评、听力的对外 JSON 都不含答案
- **账户隔离在服务端强制**：孩子的 learnerId 由会话决定
- **不随仓库分发的**：`.env`、所有 `*.pdf`（教材与讲义原件）、`media/`（题目配图与 Manim 产物）、
  `data/` 下的运行时数据库与会话。题库 JSON 里的配图文件名指向 `media/figures/`，这些图片需要自己的讲义重新导入
